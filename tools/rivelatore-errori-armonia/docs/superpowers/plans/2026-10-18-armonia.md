# Analizzatore di armonia — piano di implementazione

**Obiettivo:** implementare la CLI offline descritta in [PROGETTO.md](../../../PROGETTO.md).
**Architettura:** un pacchetto Python, music21 per la notazione, regole deterministiche e profilo TOML. Nessuna UI web, servizio o dipendenza aggiuntiva.
**Esecuzione:** direttamente in questa sessione; la specifica fornita è il riferimento autorizzato. Il checkout non contiene un repository Git utilizzabile.

## Vincoli

- Python >=3.12; music21 e defusedxml fissati alle versioni installate e verificate.
- Identità SATB stabile, tempi razionali, XML validato prima di music21.
- Severità distinta dall'affidabilità; nessun voto e nessuna certificazione musicale.
- Regole indefinite dichiarate non disponibili; report parziale con uscita 2.
- Scrittura atomica senza sovrascrittura, recupero su destinazione non scrivibile.

## Passi e verifiche

- [x] `lettura.py`: validazione e normalizzazione implementate; importazione, metadati e identità vocali verificati con music21.
- [x] `analisi.py`: timeline e ipotesi contestuali implementate; test musicali eseguiti con successo.
- [x] `regole.py` e profilo: controlli e limiti implementati; test musicali eseguiti con successo.
- [x] `report.py` e `__main__.py`: report, collisioni, errori, percorsi, recupero del salvataggio e codici di uscita verificati nei test indipendenti dalla dipendenza musicale.
- [x] Documentazione, esempio MusicXML, build sdist/wheel e installazione wheel senza dipendenze; avvio del pacchetto installato da altra cartella verificato.
- [x] Test musicali e generazione di un report reale: eseguiti usando music21 10.5.0 già installato nel sistema.

## Esito verifiche e revisione

- Ambiente Python 3.14.7; Python 3.12 non disponibile qui.
- Suite: 70 test eseguiti con successo, nessun caso saltato; inclusa l'integrazione MusicXML → CLI → report.
- `compileall` riuscito; wheel e sdist costruiti; presenza del profilo nella wheel e di esempio, specifica e helper di test nello sdist verificata.
- Revisione indipendente completata; corretti la risoluzione dopo note ribattute, i controlli delle realizzazioni successive dello stesso accordo e le alterazioni implicite delle cifre. Regressioni musicali eseguite con successo.
- `defusedxml` recuperato dalla cache locale; music21 10.5.0 riutilizzato da Miniconda con virtualenv configurato per i pacchetti di sistema. Nessuna dipendenza sostituita con uno stub.
- Corretta la lettura del metro nella prima misura; fixture corrette per conservare nomi vocali e produrre legature valide prima dell'esportazione.

## Punti di revisione

- Nessun recupero di identità da accordi che hanno perso le voci.
- Nessun collegamento artificiale attraverso pause, fermate o eventi di sole altre voci.
- Legature e armonie sostenute non moltiplicano le segnalazioni.
- Analisi incerta non genera errori confermati dipendenti dalla tonalità.
- XML con DOCTYPE MusicXML ordinario accettato senza risolvere riferimenti; entità e risorse esterne attive rifiutate.

## Validazione esterna

La validazione delle risposte musicali da parte di un docente e il corpus indipendente di valutazione non sono disponibili nel repository e non verranno dichiarati eseguiti.
